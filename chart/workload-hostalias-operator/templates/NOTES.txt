Workload HostAlias Operator has been installed successfully!

To verify the installation:

  # Check the operator pod status
  kubectl get pods -n {{ .Release.Namespace }} -l control-plane=controller-manager

  # Check the CRD is installed
  kubectl get crd workloadhostaliases.workload-hostalias-operator.buzhiyun

  # View operator logs
  kubectl logs -n {{ .Release.Namespace }} -l control-plane=controller-manager -f

Quick start example:

  # Create a sample WorkloadHostAlias
  cat <<EOF | kubectl apply -f -
  apiVersion: workload-hostalias-operator.buzhiyun/v1alpha1
  kind: WorkloadHostAlias
  metadata:
    name: example-hostalias
  spec:
    target:
      namespace: default
      kind: Deployment
      name: my-app
    hostAliases:
      - ip: "10.0.0.1"
        hostnames:
          - "foo.bar.com"
  EOF

  # Check the status
  kubectl get workloadhostaliases
  # or use short name
  kubectl get wha
